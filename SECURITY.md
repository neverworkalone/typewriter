# Security Policy

## Supported versions

Typewriter is in development and has no published stable release. Security fixes,
when needed, target the current default branch.

## Reporting a vulnerability

Please do not open a public issue or pull request for a suspected vulnerability.
Use GitHub's private vulnerability reporting form:

[Report a vulnerability privately](https://github.com/neverworkalone/typewriter/security/advisories/new)

Include the affected component or commit, the impact you observed, and concise
reproduction steps. Do not include credentials, personal data, or unrelated
third-party material.

If the private reporting page is unavailable, contact the repository maintainers
through GitHub and ask for a private reporting route before sharing technical
details. There is no public response-time commitment.

For lexical corrections and ordinary data-quality feedback, use the
[dictionary data correction form](https://github.com/neverworkalone/typewriter/issues/new?template=dictionary-data-correction.yml).
Do not post nonpublic source material there.
