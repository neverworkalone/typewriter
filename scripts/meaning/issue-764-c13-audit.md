# Issue #764 C13 meaning boundary audit

## Scope and evidence

C13(ㅈ) 전체 `data/meanings/c13_001.jsonl`~`c13_059.jsonl`을 base `6eb5d379`에서 읽고, 같은 lemma에 Meaning 행이 둘 이상인 7,646개 lemma(19,478행)를 STDICT sense 뜻풀이와 함께 펼쳐 #764 기준(독립된 어휘적 정체성)으로 하나씩 재판정했다. 실행 가능한 결정 기록은 [`issue-764-c13.json`](issue-764-c13.json)이며, `before`는 base의 해당 lemma 행과 정확히 일치하고 `groups`는 각 lemma의 모든 sense를 빠짐없이·중복 없이 나눈다. canonical JSONL은 변경하지 않았고 adjudication은 추가하지 않았다(117건 유지, DROP 없음).

이 점검은 주 에이전트 한 명의 **source-bound 자체 점검(agent self-check)**이며 독립 리뷰나 사람의 승인이 아니다.

| Measure | Before | After |
| --- | ---: | ---: |
| C13 lemmas | 39,935 | 39,935 |
| C13 Meaning rows | 58,425 | 50,309 |
| 다중 Meaning lemma | 7,646 | 4,425 |
| 재분할(repartition) 적용 lemma | — | 5,211 |
| 병합으로 줄어든 Meaning 행 | — | 8,116 |
| 전체 meanings (repo, base 시점) | 482,125 | 474,009 |

Meaning이 하나뿐인 32,289개 lemma는 병합 대상이 없어 재판정 대상에서 제외했다. 다중 Meaning이던 7,646개 lemma는 모두 읽었고, 그 가운데 5,211개를 재분할했으며 2,435개는 독립 어휘로 판단해 기존 분리를 그대로 유지했다. 재분할한 lemma 중 3,221개는 하나의 Meaning으로 합쳐졌고 1,990개는 일부만 합쳐져 여러 Meaning이 남았다.

## 판정 원칙 요약

- 한 어휘의 물리·심리·비유·문법 용법, 대상 종류만 다른 용법, 같은 구성 의미의 적용 대상 차이는 **1 Meaning**으로 병합했다(예: `좋다`의 19개 용법, `죽다`·`죽이다`의 사동·피동 짝, `지르다`의 내지르기·찌르기·불 붙이기, `주다`, `줄이다`, `지나가다`, `중성`).
- 같은 STDICT record가 번호만 달리해 묶은 sense는 병합의 **후보**로 보고, 뜻풀이에서 같은 구성 의미가 이어지는지 확인한 뒤 합쳤다(`중간`, `중기`, `주기`, `주의`, `진`의 같은 record 군). record가 같아도 서로 무관한 행위나 대상이 형태만 같으면 분리했다.
- 한자어에서 **표기·소리만 같고 한자와 뜻이 다른 독립 동음이의어**는 분리를 유지했다(예: `죽`의 죽(粥)·대나무 관악기·부사, `줄`의 도구·식물·끈, `주`의 週·株·主·朱, `집`의 가옥·시문집, `진`의 점액·왕조·시각, `징`의 못·타악기, `쥐`의 설치류·경련, `짐`의 짊·1인칭).
- 같은 구성 의미가 시대·기관만 달리 적용된 직명·관직(`좌승선`, `좌승지`, `중추원`, `집정관` 등)은 병합했고, 서로 다른 개별 대상을 가리키는 고유명(산·절·인물·작품·지명)은 분리를 유지했다.
- 의성·의태어는 같은 소리/모양의 변주(`좌르륵`, `지글지글`, `질금`, `주르륵`, `줄줄` 계열)로 보아 병합했고, `-거리다`/`-대다`/`-하다`/중첩형은 기본형 구성을 그대로 따랐다.
- 사동·피동·준말 항목(`죽이다`, `줄이다`, `쥐이다`, `줴뜯다` 등)은 본말의 sense 구성을 그대로 따랐다.
- 병합 Meaning의 gloss는 포함한 각 STDICT 뜻풀이를 **원문 그대로 이어 붙였다**(sense 순서, 동일 문장은 한 번만). 공통 추상 풀이를 새로 짓지 않았다.
- 품사는 분리·병합 근거로 쓰지 않았다.

## 한계와 미검토 범위

- 구간이 매우 넓어(7,646 lemma) 한 lemma당 판단 시간이 짧았다. 모든 lemma를 읽었으나, 긴 뜻풀이는 앞부분만 펼쳐 보고 판단한 경우가 있다.
- canonical 레코드에는 한자 원어 필드가 없어 동음 한자어의 구분은 뜻풀이와 어휘 지식에 근거한다. 이 경계의 오판 가능성(특히 `지-`·`진-`·`중-` 한자어 군)은 리뷰어가 우선 확인할 지점이다.
- 병합 gloss가 길게 이어 붙은 lemma(`좋다`, `죽다`, `주다`, `지다`, `짓다`, `주` 등)는 대표 gloss 정리를 별도로 하지 않았다.
- 같은 record의 sense는 대부분 병합했으나, 국어사전이 한 record로 묶었다는 사실만으로 합친 사례가 일부 있어 독립 어휘가 섞였을 가능성이 있다.
- 유지(KEEP)한 분리 중 일부는 보수적 판단이며, 리뷰에서 under-merge로 지적되면 같은 방식으로 추가 병합할 수 있다.
- 이 PR은 C13 범위만 다룬다. 이슈 #764의 필수 병합 사례(`쌀쌀하다`, `꽃밭`, `쌍현`, `끼적거리다`)와 필수 분리 사례(`쌍봉`, `배`, `눈`)는 다른 구간의 lemma라 이 변경에서 검증하지 않는다.

## 공유 editorial 회귀

`scripts/meaning/issue-764-c13.test.mjs`는 다음을 확인한다. 의미 판정을 문자열 규칙으로 자동화하지 않고, 실제 sense binding이 판정과 일치하는지만 확인한다.

- 스펙의 모든 `groups`가 최종 `c13_*.jsonl` 행과 sense·gloss까지 일치하고, `before`와 `groups`가 같은 sense 집합을 정확히 한 번씩 덮는다.
- 반드시 **병합**(같은 어휘의 용법 차이)과 반드시 **분리**(독립 동음이의어)할 source sense 쌍 표. 알 수 없는 sense id는 통과하지 않고 실패한다.
- 이 문서의 C13 수치 표가 체크인된 shard·스펙에서 재현된다. 저장소 전체 총계는 다른 구간 변경으로 달라지므로 테스트로 고정하지 않는다(변경 후 `validate.mjs`가 보고한 474,009에 줄어든 8,116행을 더해 계산한 base 값이다).
