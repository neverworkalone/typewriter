## 자체 점검과 provenance

초기 작성 시 두 차례 source-bound 자체 점검을 했다. 후속 PR 리뷰에서 추가 sense와 인접 후보가 제시되어 source gloss·관계·의미 행을 다시 대조하고 targeted re-adjudication을 기록했다. 첫 pass는 복수 meaning lemma의 source gloss와 모든 sense를 대조해 같은 의미축을 묶었다. 둘째 pass는 과합병, 방향이 다른 용법, gloss의 포함 범위, 보존해야 할 별도 sense와 중복 DROP 후보를 다시 확인했다. 최종 대조에서 `클립`, `크로스 패스`, `크산토필` gloss를 원 sense의 세부 범위까지 표현하도록 보정했다.

작성과 두 pass는 같은 primary agent context에서 수행한 자체 점검이다. 독립 리뷰나 사람의 편집 승인으로 표기하지 않는다. PR review는 저장소의 별도 절차를 따른다.
