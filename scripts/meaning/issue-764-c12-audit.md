# Issue #764 C12 meaning boundary audit

## Scope and evidence

C12(ㅇ) 전체 `data/meanings/c12_001.jsonl`~`c12_080.jsonl`을 base `6eb5d379537373d14f89c60206feffdb01cf7c81`에서 읽고, 다중 Meaning이던 표제어 10,329개를 #764 기준(독립된 어휘적 정체성)으로 재판정했다. 실행 가능한 결정 기록은 [`issue-764-c12.json`](issue-764-c12.json)이며, `before`는 base의 해당 lemma 모든 행과 STDICT sense 바인딩의 정확한 스냅샷이다. Canonical JSONL은 변경하지 않았다.

이 점검은 주 에이전트 한 명의 **source-bound 자체 점검(agent self-check)**이며 독립 리뷰나 사람의 승인이 아니다.

## 판정 방법

1. **같은 STDICT 표제어(record) 안의 여러 sense**는 한 단어의 다의 용법으로 보아 한 Meaning으로 병합했다(물리/심리/비유/대상/문법 차이는 분리 근거로 쓰지 않음). 원본 뜻풀이가 한 sense만 있는 record는 변경하지 않았다.
2. **서로 다른 record**는 기본적으로 독립 동음이의어로 유지했다. 한자·어원이 달라 의미 정체성이 다르면(예: `악` 惡/樂/岳, `안` 眼/案/安, `양` 洋/良/羊…) 분리를 유지했다.
3. 서로 다른 record는 독립 동음이의어가 기본이며, **원문 풀이가 같은 대상·행위·용법을 가리키면** 병합했다: 같은 성(姓) record, 같은 어휘의 피동/사동 형태, 풀이가 거의 같거나 일반 풀이와 구체·전문 풀이가 같은 행위·대상을 정의하는 중복 record(`압수`, `이거`, `유혼`, `양찰` 등), 리뷰에서 같은 어휘로 확인된 사례(`양월`, `약언`, `앵순`, `연좌` 법적 용법 등). canonical에 원어 한자 필드가 없으므로 **추정한 한자 차이만으로는 분리하지 않는다**. 원문 풀이가 서로 다른 객체·과정·장면·방향·구성어를 가리킬 때만 분리했다: `우찰`(편지/추찰), `어구`(구역/도구), `이해상반`(어긋남/반반), `음간`(성관계/일반 부정행위), `약취`(물건/사람), `운재`(목재/적재), `억매`·`예매`(사고팖 방향), `옴쏙`(씹기/함몰), `옹솥`(형태/재료), `애연하다`(흐림/화기로움), `용해`(열에 의한 용융/용액 형성). 의성·의태어와 그 준말도 같은 기준을 따른다. 파생형(`-하다`/`-히`/`-되다`)은 기본형 판정을 따른다. 허용 목록은 회귀 테스트에 고정했다.
4. 원본이 `→`로 가리키는 redirect sense는 항상 독립 Meaning으로 유지했다.
5. 병합 Meaning의 gloss는 포함한 각 STDICT 뜻풀이를 **원문 그대로 이어 붙였다**(sense 순서, 동일 문장은 한 번만). 공통 추상 풀이를 새로 짓지 않았다.

## 한계와 미검토 범위

- 표제어당 판단 시간이 짧은 단일 패스이며, 한자 동음이의어의 한자 판정은 STDICT 뜻풀이와 어휘 지식에 근거한다(원어 한자 필드를 별도 대조하지 않음). 한자어 near-paraphrase 동음어의 병합/분리 경계가 리뷰어가 우선 확인할 지점이다.
- 같은 record 안의 sense는 기본적으로 한 단어의 다의로 병합하되, 리뷰 지적 이후 두 차례 재검토했다. 1차: 같은 record의 sense 간 내용어 bigram이 겹치지 않는 2,774개 record(8,648행) 전수 열람. 2차(`이거` 지적 이후): 현재 병합 결과 중 같은 record 안에서 풀이가 서로 겹치지 않는 sense 쌍 1,826건(비유·별칭·준말 풀이 제외)을 전수 열람해 객체·행위·상태가 단절된 sense를 분리했다(`이거`·`이거하다`, `아고`, `안경(을) 쓰다`, `안심찮다`, `안아치다`, `암죽관`, `앙꼬`, `야오족`, `열구`, `역서`, `연력`, `엿방망이`, `오지`, `옥척`, `외대박이`, `요석`, `욕법`, `용연하다`, `원상`, `원심`, `월`, `육장`, `음강`, `음구`, `음신`, `의세`, `이산` 등 앞선 분리 포함). 분리 목록은 spec의 repartitions에 남아 있다.
- 잔여 위험: 위 선별은 뜻풀이 어휘 겹침 휴리스틱으로 후보를 좁힌 뒤 STDICT 뜻풀이와 어휘 지식으로 판정했으며 원어 한자 필드를 대조하지 않았다. 뜻풀이가 서로 겹치는 record 안의 이질적 sense(예: 같은 한글 표기의 다른 한자어가 한 record에 묶인 경우)와 sense 수가 2 미만인 record는 검토 대상 밖이다. 이 경계가 리뷰어가 우선 확인할 지점이다.
- record 간 병합 목록은 두 차례(554건 → 384건 → 347건 → 215건 → 현재 목록(허용 목록으로 제한)) 핵심 구성어 기준으로 전수 재독했다. 현재 목록의 각 병합은 뜻풀이상 핵심 어휘가 같다고 판정한 것이며, 확인하지 못한 오병합 잔여가 있을 수 있다.
