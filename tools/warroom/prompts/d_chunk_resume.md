#1156 D — 같은 청크 이어서

중단된 청크 {{chunk_no}}를 이 세션에서 이어간다. 청크 view와 카드는 이 세션에 이미 있으므로 다시 읽거나 요청하지 않는다. 카드의 규칙 그대로, 아직 `{{decisions}}`를 저장하지 못한 Sense를 마저 판독해 카드의 **한 번의 셸 호출**(판정 파일 작성 + `save`)로 저장한다. 저장은 거부되면 아무것도 저장하지 않으므로 청크의 모든 판정 대상 Sense를 다시 한 번씩 넣는다. 정상 저장되면 즉시 종료한다. `AGENTS.md`, `docs/`, Git, `gh`, 다음 청크 진행, 조립, commit, push, PR 생성은 하지 않는다.

이미 `{{decisions}}`가 있지만 save/진단이 없다면 새 검색이나 재판정부터 하지 않는다. 파일과 실행 명령 상태를 확인하고, 필요한 경우 기존 판정 의미를 보존해 출력 형식만 국소 수정한 뒤 save를 실행한다. `{{searches}}`의 증거는 보존한다. 실제 미저장이고 현재 세션이 안전하게 이어질 때만 bounded 재개한다.
