## Shared Stage 2 decision policy (#2544)

- Do not discover candidates or revisit Stage 1 production. For **each listed candidate**, judge its exact source Sense/full gloss against existing approved peers (`P`), saved decisions (`Q`), and other same-Sense candidates. **Stage 2 owns final editorial admission**; a semantic connection by itself is not enough.
- **Two gates before assigning Type/Tier:** (1) Does this path connect to the *actual* source Sense? (2) Does it give a writer a distinct useful word choice, nuance, mood, image, action, scene, sensation, or imaginative direction? Drop if either fails. No Keep/Drop quota. A low Tier is not a parking place for an editorially useless relation.
- **Editorial Drop:** trivial inflections/same-root ending variants, same-concept nominalization, unhelpful repetition, generic synonym with no distinct expression, accidental context objects/places and unsupported multi-hop associations. Stage 1 already excludes obvious `깜빡대다→깜빡이다`, `건축→건축가`, `조퇴하다→조퇴`, `팔딱하다→팔딱팔딱`; only judge leftovers that actually appear in this chunk. No second Stage 1 scan or mechanical suffix blacklist.
- **Protect useful creative paths:** keep intelligible but rare/indirect or low-priority imagery when it genuinely helps writing. `깜빡대다` memory Sense→`가물가물`, light Sense→`점멸/명멸` are positive controls. `어정대다→낙타` is **not an automatic Drop**: decide its value from the source Sense and plausible creative path. Judge `팔딱하다→심장` by its actual Sense. A different POS, gloss mention, or unfamiliarity never settles admission alone.
- **Drop code in the existing `D` answer:** use `D e` when a candidate connects to the exact source Sense but has no independent writer-facing expression value; use `D x` when it is unrelated or bound to the wrong Sense. Stage 2 must never output `z`, prose, `editorial:`, or `edit`; `z` is reserved for Stage 3 orphan accounting. The gloss-name counterexample check applies to `x` and is bypassed for `e` and `z`. Decide the meaning and expression value from the source-bound evidence, then output only the code; do not bypass verification or alter persisted JSONL fields.
- For a **kept** candidate, choose its actual type, not default `association` or fold `scene`/`sensory` into it or `mood` into `near`.
  - `near`: lexical neighbor or nuance close to the source; `mood`: emotion, atmosphere, or tone.
  - `scene`: situation/place/scene; `sensory`: sound/smell/perception/experience; `action`: related act or motion.
  - `association`: broader concept/object/topic when no more specific type fits. Do not use `direct` or `antonym`.
- Only for kept candidates, set Tier (`relevance: 1..9`) relative to `P`, `Q` and same-source/UI-group peers: `near`/`mood` = 말의 결; `scene`/`sensory`/`action`/`association` = 연상. Tier 1 is near-substitutable; 3 strong; 5 useful; 7 broader; 9 peripheral **but still valuable**. Even values interpolate. 연상 Tier 1 needs a real informal synonym candidate. Never rank for quota or to avoid a deserved Drop.
- For an ID↔ID relation, the stored edge is shown both ways; consider **both directions' writer value** before admission. Do not re-adjudicate already-approved duplicate/reverse-covered relations. Bind an ID only after comparing *every supplied same-spelling target Sense/full gloss* and finding an exact match; otherwise keep an admitted target text-only and list every target alias shown. If none exists, omit the target field.
