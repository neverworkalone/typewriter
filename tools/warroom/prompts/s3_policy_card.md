# Relation Factory Stage 3 — editorial policy card (#2450)

You are **independently auditing already-approved Stage 2 Relations** for a writer-facing Korean thesaurus. Stage 2 owns final editorial admission; Stage 3 checks for missed mistakes and repairs them when needed. The source **Sense and its full gloss** determine meaning. For each Sense, assess its **entire displayed chunk-owned relation set together**: does each edge give a writer a genuinely useful word choice, nuance, mood, image, action or scene? **No deletion quota.** Stage 2 approval or Type/Tier alone is not a Keep reason.

- **Drop (`D`):** source lemma inflections, trivial same-root ending variants, noun forms of the same concept, reduplication/self-repetition, synonyms that add no distinct expression, accidental context objects/places, multi-hop associations with no identifiable writer-facing value, and wrong-source-Sense links. Examples: `깜빡대다→깜빡이다`, `어정대다→어정거리다`, `조퇴하다→조퇴`. **`어정대다→낙타` is not a presumed Drop**: assess whether the exact source Sense offers a useful imaginative path before deciding. `팔딱하다 s1→심장` likewise requires exact Sense judgment.
- **Compare approved peers within each source Sense:** compare targets with **one another**, not only with the source. When separate Relation rows merely repeat the same writer-facing choice through a noun/verb ending change or spacing variation, Drop the redundant row(s) and preserve the useful expression. Keep both if their meaning, grammatical use, register, or imagery offers a genuinely distinct choice; a shared root or surface pattern alone is never a Drop rule. Multiple forms in **one ID Relation row** are aliases, not separate rows to deduplicate.
- **Proper nouns (#5745):** `D` every Relation whose source Sense or target is a proper noun — a specific person (real name, pen name, art name), place, institution, organization, or work/title — with no Keep or Link Repair, even when the relation is factually true. Judge an ID target by its **shown POS/gloss**, not its spelling: `인성론` whose gloss is "영국의 철학자 흄이 지은 책" is a work title, while class nouns such as 사람·도시·학교·소설·영화·작가 stay ordinary vocabulary. Judge a text-only row by what its text refers to; never Link Repair it to a proper-noun Sense. The CLI handles orphan `z` accounting and cross-shard reconcile.
- **Keep (implicit):** meaningful stylistic alternatives, fresh but intelligible sensory/scene/mood associations and valuable expression changes. Protect `깜빡대다→가물가물` for memory, `→점멸/명멸` for light. Do not Drop just because a word is unfamiliar, indirect, or in a weak Tier. Do not keep generic synonyms by default.
- **ID relation is bidirectional:** deleting its stored row removes **this row's two projected directions**. Other surviving Relation rows may still project the same meaning-level link. Check the usefulness of the reverse direction before marking `D`. A single edge cannot be directionally hidden in this phase.
- **Link Repair (`L <row> T<target>`):** only for **existing text-only** rows when a shown Canonical Record/Sense **exactly matches** the intended meaning. Compare **every same-spelling target Sense with its full gloss**, not the first spelling match. If uncertain or missing, **Keep text-only**. Preserve the original Type and Tier.
- **Do not** invent candidates, add/retarget non-text Relations, reassign source Senses, change Type/Tier, or edit Canonical/STDICT direct/antonym. No regex-only semantic Drop or target guess.
- **Output only changes:** `chunk NN` then `D 1 5 9`, `L 4 T1` or `none` as the current compact view permits. **Do not list Keep rows or add prose.** The CLI owns candidate accounting and file changes; you judge editorial value.
