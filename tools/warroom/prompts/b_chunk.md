B Stage 1 청크 답변 (배치 {{batch}}, 청크 {{chunk_no}})

너는 이 청크 하나의 Candidate를 **최종 답변으로만** 돌려준다. 파일 읽기·저장·Git·`gh`·`AGENTS.md`/문서 열람·다음 청크·PR·서브에이전트·웹 조회는 하지 않는다(도구를 쓰지 않는다). 다른 방식·모델의 후보나 이전 청크는 모른다. 저장·검증·merge·PR은 Supervisor가 한다.

## 입력
아래 view의 각 줄 `S<n> ⇥ sense_id ⇥ 표제어 [동형이의 번호] ⇥ 품사 ⇥ search_forms(비면 표제어만) ⇥ 전체 뜻풀이`가 **정확한 출발 Canonical sense**다. 동음이의어·다의어를 혼동하지 않는다.

## B 단일 장면 탐색 (sense마다)
1. 출발 sense의 뜻을 확정한다.
2. 그 뜻이 살아 있는 **구체적인 가상 장면 하나**를 상상하고, 장면의 인물·사물·행동·감각·정서·장소·상황·간접 연상에서 어휘를 첫 탐색에 충분히 발굴한다. 개수 목표·상한으로 조기 종료하지 않는다.
3. 두 번째 장면·독립 재탐색은 하지 않는다. 뜻풀이 동의어 나열로 장면을 대신하지 않는다. 전문어·고유명사·단일 지시 대상에는 가짜 사건을 꾸미지 말고 결속된 주변 어휘만 발굴한다. 장면 서술·근거는 답변에 쓰지 않는다(어휘 문자열만).

## 최종 표현 검사 (답변 전에 모든 후보 문자열에 적용)
- 허용: 독립 단어(느슨한 연상·이미지·사물·감각·정서·동사·다른 품사 포함), 제시어를 포함하되 별도 어휘성이 있는 합성어(`건축→건축가`), 장면을 여는 **간결한 이미지·감각 표현**(평범해도 보존, 예 `수괘→겨울 아침`).
- 금지(0개): 장면을 서술하는 문장·서술절·특정 사건/행동/과정 설명(어미 변경·명사구 위장 포함), 뜻풀이 속성+범주 재포장·공백만 지운 구·제시어 수식 구, 표제어 자체·괄호 주석만 덧붙인 표기, 같은 sense 안의 정확 중복, 출발 sense를 오해했거나 사실이 아닌 연결.
- 공백·길이만으로 합격/불합격을 단정하지 않는다. 연상 강도·Tier·관계 type·채택은 Stage 2가 판단하니 사전 탈락시키지 않는다.

## 출력 형식 (이것만)
```
BEGIN chunk {{chunk_no}}
S1<TAB>후보<TAB>후보
S2
S3<TAB>후보
...
END chunk {{chunk_no}}
```
- view의 **모든 `S<n>`을 정확히 한 번**, 번호 순서대로. 후보가 없으면 `S<n>`만 쓴다.
- 구분자는 실제 TAB 한 글자. 후보 안에 TAB·줄바꿈을 넣지 않는다. 설명·근거·코드펜스·다른 텍스트는 쓰지 않는다.
- 저장 거부 메시지가 오면 **지목된 `S<n>` 줄만** 같은 형식으로 다시 답한다.
