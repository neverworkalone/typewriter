B Stage 1 청크 답변 (배치 {{batch}}, 청크 {{chunk_no}})

너는 이 청크 하나의 Candidate를 **최종 답변으로만** 돌려준다. 파일 읽기·저장·Git·`gh`·`AGENTS.md`/문서 열람·다음 청크·PR·서브에이전트·웹 조회는 하지 않는다(도구를 쓰지 않는다). 다른 방식·모델의 후보나 이전 청크는 모른다. 저장·검증·merge·PR은 Supervisor가 한다.

## 입력
아래 view의 각 줄 `S<n> ⇥ sense_id ⇥ 표제어 [동형이의 번호] ⇥ 품사 ⇥ search_forms(비면 표제어만) ⇥ 전체 뜻풀이`가 **정확한 출발 Canonical sense**다. 동음이의어·다의어를 혼동하지 않는다.

## 장면 어휘 선택 — 장면 발굴과 동시에 적용
가상 장면의 설명이나 원뜻풀이의 묘사를 일단 후보로 적어 두었다가 나중에 솎지 않는다. 장면에서 표현이 떠오르는 **그 순간**, 출발 sense에 연결되는 **별개 어휘·장면·감각·정서**인지 판별해 적격한 것만 기록한다.
- **채택:** 장면의 사람·사물·장소·행동을 가리키는 독립 단어·동사·합성어, 의미를 새 이미지·감각·정서로 넓히는 간결한 표현(`수괘[서리]→겨울 아침`, `산뜩→가슴 철렁`). 평범하고 약한 연상도 보존한다.
- **비채택:** 뜻풀이의 속성+범주를 잘라 낸 표현(`가는솜방망이→노란 꽃`), 뜻풀이의 행위를 명사화한 표현(`감필하다→줄여 쓰기`), 서술구로 축약한 표현(`보급→널리 퍼지다`), 장면의 사건을 설명하는 절·문장, 표제어+단순 수식.
`노란 꽃` 같은 문자열 자체가 항상 금지된 것은 아니다. **그 출발 sense의 뜻풀이를 기계적으로 반복하는 경우**에만 제외한다. 원뜻풀이에 있는 독립 단어, 다른 의미 경로를 여는 짧은 표현은 보존한다. 수를 채우려 문구를 조립하거나 두 번째 장면·별도 AI 검수 턴을 만들지 않는다.

## B 단일 장면 탐색 (sense마다)
1. 출발 sense의 뜻을 확정한다.
2. 그 뜻이 살아 있는 **구체적인 가상 장면 하나**를 상상하고, 장면의 인물·사물·행동·감각·정서·장소·상황·간접 연상에서 어휘를 첫 탐색에 충분히 발굴하면서 위 기준에 맞는 후보만 바로 선택한다. 개수 목표·상한으로 조기 종료하지 않는다.
3. 두 번째 장면·독립 재탐색은 하지 않는다. 뜻풀이 동의어 나열로 장면을 대신하지 않는다. 전문어·고유명사·단일 지시 대상에는 가짜 사건을 꾸미지 말고 결속된 주변 어휘만 발굴한다. 장면 서술·근거는 답변에 쓰지 않는다(어휘 문자열만).

## 출력 형식 (이것만)
```
BEGIN chunk {{chunk_no}}
S1<TAB>후보<TAB>후보
S2
S3<TAB>후보
...
END chunk {{chunk_no}}
```
- view의 **모든 `S<n>`을 정확히 한 번**, 번호 순서대로. 후보가 없으면 `S<n>`만 쓴다.
- 구분자는 실제 TAB 한 글자. 후보 안에 TAB·줄바꿈을 넣지 않는다. 설명·근거·코드펜스·다른 텍스트는 쓰지 않는다.
- 저장 거부 메시지가 오면 **지목된 `S<n>` 줄만** 같은 형식으로 다시 답한다. 기존 후보를 정정할 때는 이미 발견한 유효 후보를 보존한다. 명백하게 부적격한 후보만 제거하고 새 발견은 추가한다. 지목된 Sense를 고친다는 이유로 그 Sense의 정상 후보까지 재생성·삭제하지 않는다.
