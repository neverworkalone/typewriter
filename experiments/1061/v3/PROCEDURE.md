# D 생산·검증 절차 V3 — 발굴 우선, 검증 분리

V2(`../v2/PROCEDURE.md`)의 G1–G4는 정확도를 높였지만, **원문에 정확히 등장한 표현만** 인정하고 lemma 부분 문자열·뜻풀이 어휘 겹침을 기계적으로 제거해 발굴량을 과도하게 줄였다. V3는 제거 규칙을 완화하고, **발굴(Phase A)과 검증(Phase B)을 분리**한다. 특정 표제어를 위한 예외는 두지 않는다.

## 1. 유지하는 것

- Candidate JSONL v1 출력 계약.
- 검색 상태 구분(`ok` / `zero_hits` / `zero_after_filter` / `search_failed`). 실패는 빈 후보로 기록하지 않는다.
- 3자 이상 trigram FTS, 2자 bigram postings, postings 부재·NULL 시 `LIKE` 대체, 공백 표현의 정확 일치 확인, `하다` 용언 활용형 보강.
- 원문·문단 ID·검색 로그는 저장소 밖에만 둔다.

## 2. Phase A — High Recall Discovery

1. **초기 4문맥**으로 시작한다. 유효한 문맥이 확인되거나 판단이 모호하면 **최대 16문맥**까지 확장한다.
2. 확장은 **서로 다른 문서·위치**를 우선한다. 같은 문서는 최대 2문맥, 동일 문단 중복은 제외한다. 검색 순위만 따르지 않는다.
3. 유효 문맥마다 다음 관점을 **각각** 검토한다. 이는 할당량이 아니라 탐색 목록이다.
   - 실제 결합 표현
   - 행동·사건
   - 상황·맥락
   - 원인·결과
   - 대조·연상(비유·상징 포함)
4. 첫 후보에서 멈추지 않는다. 같은 문맥의 행동·결과·주변 상황·대조 표현을 추가로 검토한다.
5. 후보는 원문에 그대로 있을 필요가 없다. 다만 **출발 sense와 문맥 사이의 설명 가능한 경로**가 있어야 한다.
6. 문맥이 빈약하면 상상으로 채우지 않는다.

## 3. Phase B — High Precision Validation

후보마다 세 조건을 **독립적으로** 확인한다.

1. **Sense accuracy** — 출발어의 정확한 sense와 연결되는가. 동음이의어·다른 sense의 용례는 제외.
2. **Context grounding** — 실제 문맥에서 설명 가능한 관계인가. 단순 공출현은 제외.
3. **Editorial value** — 작가에게 표현·연상의 확장을 주는가. 뜻풀이 반복은 제외.

세 조건을 모두 통과한 후보만 남긴다. V2와 달리 다음은 **제거 사유가 아니다**.

- 후보가 source lemma를 부분 문자열로 포함함(단, lemma와 정확히 같으면 제외).
- 후보 어휘가 뜻풀이와 일부 겹침(단, 뜻풀이만 재작성한 후보는 제외).
- 후보가 원문에 문자 그대로 없음(문맥 유도·활용형 허용).

## 4. 근거 기록과 표현 구분

후보별로 로컬 근거에 다음을 기록한다.

- `verbatim`: 인용 문맥에 후보 문자열이 그대로 있음.
- `derived`: 어간·어미 변화, 어순·조사 차이, 문맥에서 설명 가능한 행동·상황·결과·연상.

`derived`를 원문 인용으로 보고하지 않는다. 산출물에는 문자열만 남기고 근거는 로컬에만 둔다.

## 5. 게이트 (자동, 최소)

자동 검사는 계약 위반만 잡는다.

- G1: 같은 sense 안 정확 중복 금지.
- G2: source lemma와 정확히 같은 문자열 금지.
- G3: `search_failed`가 하나라도 있으면 산출 중단.
- G4: 후보가 비어 있지 않은 trimmed 문자열인지 확인.

sense·문맥·편집 가치는 자동 문자열 필터가 아니라 Phase B 판정으로 처리한다.

## 6. 절차 점검과 적용

1. 배치에서 **다양한 유형의 표본**(약 100 sense)으로 절차를 점검한다.
2. 문제가 없으면 같은 규칙으로 배치 전체에 적용한다.
3. 후보 수 목표는 두지 않는다. 다른 생산자의 수치는 품질 기준값이지 할당량이 아니다.

## 7. 보고 의무

- 총 후보 수, 후보가 있는 sense 수, 활성 sense당 평균.
- sense당 확인한 문맥 수 분포(초기 4 + 확장).
- `verbatim` / `derived` 분포.
- V2 대비 유지·신규, V2가 부당하게 제거한 사례.
- 남은 의미 오류와 검증 한계.
- 검색·생산 비용(가능한 범위).
