# 016/01 블라인드 재현 조건

이 회차는 **V5 개발이 아니라 V4 절차의 블라인드 재현**이다. `experiments/1061/v4/PROCEDURE.md`의 검색·생성·검증 규칙을 변경하지 않고 처음 보는 배치에 적용했다.

## 고정 조건

- 대상: `data/canonical/stdict-0016.jsonl` 1–500행 (500 records / 565 senses), Canonical SHA-256 `04dedfe2…5524`.
- 검색: `written-corpus-2025.sqlite` 읽기 전용. V4와 동일한 trigram FTS, bigram postings, LIKE 대체, `하다` 활용형 보강. 16문맥 저장, 문서당 최대 2문맥.
- V3/V4에서 얻은 후보·문맥은 재사용하지 않았다. 이 배치의 Canonical과 말뭉치만 사용했다.
- Codex `016_01` 산출물과 다른 생산자 후보는 열람하지 않았다.
- 특정 표제어 예외·하드코딩 없음. 후보 수 목표 없음.
- 출력: Candidate JSONL v1. 계약 검증 `{"recordCount":500,"senseCount":565,"candidateCount":240,"emptySenseCount":438}`.

## 절차 적용 방식

V4는 "기존 후보 풀의 전수 감사"를 전제한다. 새 배치에는 기존 풀이 없으므로, 같은 V4 규칙으로 ① 검색·5관점 발굴로 후보 풀을 만든 뒤 ② Phase A–D 감사(의미 결속, 문맥 근거, 의미 중복, 표제어 결합 정리)를 출력 전에 적용했다. 절차 문구나 임계값은 바꾸지 않았다.

## 남은 오류·한계

- `zero_hits` 233개는 이 코퍼스에 해당 표제어 용례가 없는 경우다. 빈 후보는 미실행이 아니다.
- 동음이의어가 많은 배치라 4문맥에서 다른 뜻만 확인된 sense가 많다. 추가 문맥 확장은 후보가 없는 sense 일부에만 적용했다.
- 문맥 유도 30개는 원문 인용이 아니다.
- 표제어 포함 28개는 대부분 전문 용어·관용구지만, 평가자가 독립 가치를 낮게 볼 수 있다.
- Codex 동등성은 판정하지 않았다. 이 배치의 Codex 산출물을 읽지 않았으므로 비교는 독립 평가자 몫이다.
