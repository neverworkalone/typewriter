# C V6 실행 기록 — 013/01 (500 records / 560 senses)

Issue #1061 / #1109. 이 문서는 관측값과 한계만 기록한다. 원문·발췌문·SQLite·
검색 로그는 넣지 않는다. 후보 문자열은 산출물이므로 예시로만 인용한다.

감사 대상인 **자신의 C V5 013/01 65개**뿐이다.

## 2. PRE-FLIGHT와 파일럿

- 500 records / 560 senses를 Canonical 순서로 동결하고 sense별 상태를 만들었다.
- 결정적 표본(원본 순서 1–25 records)으로 파일럿을 실행했다. 검색 가능 sense,
  다의어, 검색 결과 없는 sense, 이전 후보가 있던 sense가 포함됐다.
- 파일럿에서 확인한 공통 오류: (a) 1자 search form이 다른 단어를 대량으로
  끌어오는 문제 → 1자 표제어는 `UNSEARCHABLE`, 1자 용언 어간은 일반 어미
  결합으로만 검색, (b) 짧은 시행·대사만으로는 장면이 부족한 문제 → 앞뒤 단위를
  붙여 문맥 창 구성. 이후 500 records 본 실행에서 규칙을 바꾸지 않았다.

## 7. PASS E/F — 동일 기준 감사와 재발굴

감사 대상은 **기존 V5 65개 + V6 신규 176개 = 241개**다. 출처 예외 없이
Sense·Evidence·Writer value·Independence·Counterargument를 적용했다.

| 판정 | V5 65개 | V6 176개 | 합계 241 |
|---|---:|---:|---:|
| `KEEP` | 15 | 156 | 171 |
| `REWORK` | 1 | 5 | 6 |
| `DROP` | 34 | 15 | 49 |
| `UNCERTAIN` | 15 | 0 | 15 |

- V5 65개의 KEEP률은 23.1%다. 자동 KEEP은 없었다.
- V5 `DROP`의 주요 유형: 단순 공출현(사물·인물·장소·기관), 어의 혼입(정열≠기세,
  우둔≠나약), 정의 반복, 다른 sense의 수식어, 근거 확인 불가.
- V5 `UNCERTAIN` 15개는 기존 실행의 근거 로그가 남아 있지 않아 현재 문맥으로
  재확인하지 못한 항목이다. 최종 후보로 승격하지 않았다.
- V6 `DROP` 15개: 기존 후보와 동일 문자열 9개, 의미 중복 4개, 파편·어색한 구성
  1개, 공출현 1개.
- `REWORK` 6개 중 5개는 같은 VERIFIED 문맥에서 더 나은 관계로 교체한 신규
  후보이고, 1개(V5 `모두가 검다고 말하다`)는 `사람마다 다르게 보는 빛깔`로
  재구성했다.
- 재발굴로 추가된 예: `높은 곳을 무서워하다`, `길을 닦아나가다`, `건배 건배!`,
  `돈이 한창 마른 때`, `문단을 삶의 터전으로 삼다`.

## 11. 한계와 미완료·미검증

1. **독립 감사 없음.** 모든 판정은 생산자 자기 감사이며, 오너 측 별도 평가를
   대체하지 않는다.
2. **문맥 상한 16.** 16개를 넘는 문맥은 읽지 않았다. 53개 sense가
   `INSPECTED_16`으로 끝났으므로, 그중 일부는 더 읽으면 추가 관계가 나올 수
   있다.
3. **검색 형태의 한계.** 고어·한자 혼용·불규칙 활용·1자 표제어에서 probe가
   놓친 용례가 있을 수 있다. 4개 sense는 `UNSEARCHABLE`이다.
4. **문맥 선택의 편향.** 다양성 순위는 결정적이지만, 작품·장르 분포가
   소설·수필·시에 치우친 승인 인덱스의 성격을 그대로 반영한다. 희곡·구비문학
   등은 없다.
5. **긴 한문·번역체 문맥.** 일부 문맥은 한자 병기와 번역체 때문에 sense 확인이
   어려워 `AMBIGUOUS`/`REJECTED`로 처리했다. 이는 문맥 부재와 다르다.
6. **2차 7관점 순회의 수확.** 2차 순회에서 23개(13.1%)가 추가됐다. 1차 판독만
   으로 완료를 선언했다면 놓쳤을 관계가 있다. 다만 2차 순회도 사람의 독립
   재검토는 아니다.
7. **이전 V5 근거 로그 부재.** V5 65개 중 15개는 현재 문맥으로 재확인하지
   못해 `UNCERTAIN`으로 남겼다. 삭제하지 않았지만 최종 후보에는 넣지 않았다.
8. **개발 배치.** 013/01은 V5 블라인드 실험 결과를 이미 확인한 개발 배치다.
   V6 결과를 블라인드 성과로 주장하지 않는다.
9. **다른 생산자와 비교하지 않음.** Codex 동등성은 이 문서에서 판정하지 않는다.
