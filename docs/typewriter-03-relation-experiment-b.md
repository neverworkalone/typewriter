# Typewriter 0.3 — 실험 B: AI 구성 장면 경유 말의 결·연상 생성 파일럿

- 이슈: **#844** (담당 실험 **B — Imagined scenes**), 상위 #841, 오너 정책 #838.
- 산출물: 이 보고서 **1개 파일만**. Canonical/제품/DB/다른 실험군 산출물은 변경하지 않았다.
- 방식 경계: AI가 **먼저 서로 구분되는 가상의 상황·장면을 만들고**, 그 장면에서 후보를 추출한다.
  **실제 문학·말뭉치 자료를 검색·공급하지 않았다**(corpus/literature DB 미사용, 외부 검색 미사용).
- 라이선스·산출물 경계: 본 보고서는 후보 관계·독립 편집 의견과 **출처를 재현하지 않는 메타데이터**(표제어,
  record/sense ID, 동음이의어 번호, 품사, #841이 지정한 출발 의미 힌트)만 담는다. STDICT 정의문·문학/말뭉치
  원문·발췌·SQLite는 전혀 복제하지 않는다(출발 뜻풀이 본문은 §2에서 인용하지 않음).

## 1. 고정한 공통 규약 (생성 시작 전 확정)

### 1.1 고정 입력 프롬프트 (출발 의미마다 동일, `{...}`만 치환)

```text
너는 한국어 작가용 사전(Typewriter)의 말의 결·연상 후보를 만드는 편집 보조자다.
실제 문학·말뭉치·외부 자료를 검색하거나 인용하지 않는다. 아래 사전 입력만 사용한다.
[출발 입력]
lemma: {lemma}
pos: {pos}
sense: {gloss}        ← 이 뜻 하나에만 결속한다
[허용 타입] near, mood | scene, sensory, action, association
[금지] direct, antonym 신규 작성 금지. 새 표제어/ID 생성 금지. 자기 자신 연결 금지.
[절차]
1) 위 뜻에 맞고 서로 구분되는 가상의 상황·장면을 3~4개 먼저 만든다.
   각 장면은 공간·시간·인물·행동이 서로 달라야 하고 정서를 한 줄로 적는다.
   명사 나열, 비유 남발, 같은 장면의 반복은 피한다.
2) 각 장면에서 작가가 실제로 쓸 법한 표현·단어를 골라 후보를 최대 8개 만든다(0개 허용, quota 없음).
3) 후보마다 relation_type과 relevance(1..9, 같은 출발 의미·같은 UI 그룹 안 상대)를 매기고
   이유를 한 줄 적는다. 정확한 기존 표제어·뜻이 있으면 그 대상 sense까지 지정한다.
[출력] 장면 목록 → 후보 표(target_text, relation_type, relevance, reason) → 제외/보류 후보와 이유
```

### 1.2 선정 예산 (비교 예산이며 제품 quota 아님)

| 항목 | 값 |
| --- | --- |
| 출발 의미 | #841 고정 코호트 **8개 전부** |
| 의미당 생성 후보 상한 | **8개**(0개 허용) |
| 의미당 선행 장면 | **3~4개** |
| 전체 후보 상한 | 8 × 8 = 64 |
| 반복 | 출발 의미마다 1회(동일 프롬프트). 재생성·후보 보정 없음 |
| B 방식 특유 추가 입력 | 없음(모델이 스스로 만든 장면만 사용). 코호트에 없는 단어·테스트 문구 추가 없음 |

### 1.3 모델·실행환경·교란요인 (공개)

- 모델: **DeepSeek V4.1 Flash Free** (OpenCode 하네스, provider `opencode`).
- 실행: **단일 대화형 에이전트 세션**. temperature/seed/최대 출력 토큰은 하네스가 노출하지 않아 **고정 불가**.
  검색·브라우저·외부 API 도구를 쓰지 않았고, 서브에이전트나 다른 모델/세션에 생성·검수를 위임하지 않았다.
- 교란: A/C/D와 **작업자·모델·실행환경이 다르다**. 따라서 네 방식의 차이는 알고리즘 차이와 작업자/모델 차이가
  섞인 비교다. 이 보고서는 B 방식의 실제 결과만 기록하며 다른 방식의 우열을 추측하지 않는다.

대안으로 둔다. 네 실험군의 분모를 맞추기 위해 이 선택과 근거를 명시하며, 힌트가 `-s3`을 의도했다면
이 절의 후보 대부분(액체의 이동 이미지)은 그대로 유효하다.

## 3. 출발 의미별 결과

각 항목은 ⑴ 장면(후보 생성보다 **먼저** 만든 중간 산출물) → ⑵ 후보 표 → ⑶ 제외/보류 순이다.
`target_record_id_or_null`은 현재 Canonical 조회 결과이며, **없으면 새 ID를 만들지 않고 text-only**로 두었다.
`relevance`는 같은 출발 의미·같은 UI 그룹(말의 결 = near/mood, 연상 = scene/sensory/action/association)
안에서의 상대 우선순위다. `결정`은 **생산자 잠정 평가**(keep/revise/reject)이며 최종 판정이 아니다.

**#841 공통 컬럼 대응:** `source_lemma`/`source_record_id`/`source_sense`는 각 절 제목과 §2 표에, `method`는
`B-scene`(장면 경유)에, `target_text`/`target_record_id_or_null`/`relation_type`/`relevance`/
`provisional_decision`/`reasoning(non-quoted)`은 아래 표의 `target_text`/`target_record_id`/`type`/`relevance`/
`결정`/`reason` 열에 각각 대응한다. `failure_reason`은 표에 별도 열을 두지 않고 각 절 **⑶ 제외/보류** 및
미해당 시 `—`로 기록했다.

  A/C/D와 같은 엄격한 "생성 8개" 조건의 비교에는 이 한계를 감안해야 한다.
- text-only 2건: `보고 싶다`(그리움), `기다림`(기다리다). **lemma뿐 아니라 Canonical `search_forms`와 의미를
  함께 확인**했고 둘 다 대응 표제어가 없어 신조 ID 없이 텍스트로만 기록했다. `장원급제`는 `장원 급제`의 검색
  이형태로 확인되어 `w274079-s1`로 ID 결속했다(리뷰 반영).

### 5.2 관계 타입 분포

| type | 개수 | 비고 |

### 5.3 중복·sense 오류·공식 관계 반복 점검

- **정확한 sense 결속:** 모든 ID 후보를 실제 조회로 검증했고, 동음이의어/다의어 오결속 위험 후보는
  사용하지 않았다(예: `물감 w124634-s2`(그림 화구)를 쓰고 `w124634-s1`(물들이는 물질)·`w424678`(감 과실)
  아님, `유생 w466040`(선비) not 곤충/생명, `선비 w443813`(학식인 사람) not 비/돛삯/이전 잘못,
  `낙방 w409356`(s1 과거) not 극락, `급제 s2`).
- **공식 관계 반복:** 나그네의 `direct` 4개, 과거의 `direct` 6개는 후보에서 **의도적으로 제외**했다.
- **중복:** 그리움 `회상`, 쓸쓸하다 `적막`, 흐르다 `흘러내리다`, 번지다 `잉크`를 중복으로 제외했다.
- **text-only 재검증(리뷰 반영):** text-only 후보는 lemma만이 아니라 Canonical `search_forms`와 대상 sense까지
  함께 확인했다. 그 결과 `장원급제`(→ `장원 급제 w274079-s1`)를 ID 결속으로 **정정**했고, `보고 싶다`·
  `기다림`은 대응 표제어 없음이 확인되어 text-only로 유지했다.
- **부적절 타입/억지 연상:** 없도록 상한 안에서 밀도를 조절했고, 정서 일반화("모든 나그네=외로움")를 피했다.

## 8. 실패·누락·데이터 제약

- **검색 미사용은 제약이 아니라 B 경계다.** 실제 문학/말뭉치 문맥 0건, 외부 검색 0건.
- **모델/설정 비공개 한계:** temperature·seed·출력 토큰 상한을 고정할 수 없어 재현성이 완전하지 않다.
  같은 프롬프트로도 후보·장면이 달라질 수 있다.
- **sense 힌트 모호성:** §2의 흐르다 `-s12` vs `-s3` 및 문턱 homograph(2)·번지다 homograph(1) 선택은
  힌트 해석에 따른 판단이다. 네 실험군이 다른 sense를 고르면 분모가 어긋날 수 있다.
- **text-only 미구현:** 현행 제품은 target ID가 없는 관계를 노출하지 못한다(조건 C). 본 보고서는 초안 분류만
  기록하며 제품 동작을 주장하지 않는다.
- **낙방/급제/과거장 같은 과거 관련 ID는 표제어 자체가 archaic register**라 일반 글쓰기 빈도가 낮을 수 있다
  (writer usefulness는 편집 우선순위일 뿐, 후보 자격과 별개).

## 9. 독립성·불확실성·자기평가 고지

- 이 보고서의 keep/revise/reject와 Tier는 **생산자 자체 잠정 평가**다. 독립/인간 리뷰가 아니며, 최종 승자나
  방식 우열을 단정하지 않는다.
- "채택률 63/64" 같은 수치는 **생산자가 자기 후보를 자기 기준으로 본 값**이라 실제 품질 지표가 아니다.
- 샘플이 8개 출발 의미·64개 후보로 작아 0.3 전체 생성 품질로 일반화할 수 없다.
- 작업자·모델·실행환경이 A/C/D와 다르므로 순수 알고리즘 비교가 아니다.
- 다음 확인 필요: 다른 실험군이 코호트의 각 뜻에 **같은 sense ID**를 결속했는지(#841에서 대조), 그리고
  독립 평가자가 본 후보의 실제 유용성·Tier 적합성을 어떻게 보는지.
