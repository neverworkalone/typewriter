# M1 pilot scope — lexical/editorial model

## 목적

이 문서는 M1에서 검토할 **검색 출발어**의 선정표다. 목록 자체는 lexical
canonical record가 아니다. 아직 검수하지 않은 후보, 외부 자료, 메모는 저장소
밖의 임시 작업 영역에 둔다. `data/canonical/`에는 사람이 검수한 Typewriter
레코드만 들어간다.

M1의 목표 수는 정확히 300이라는 숫자를 맞추는 것이 아니라, 작가가 문장을
고치며 실제로 다시 찾을 법한 말의 결을 작은 표본으로 고르게 흔들어 보는
것이다. 따라서 아래의 300개는 출발어 300개로 집계하고, 관계를 완결하기 위해
추가되는 대상어는 별도 집계한다.

## 집계 규칙

- **출발어**: 사용자가 검색을 시작할 수 있도록 선정표에 올린 표제어. 활용형은
  별도 출발어로 세지 않는다.
- **참조 대상어**: 관계의 도착점으로 필요하지만 선정표의 출발어에는 없는
  Typewriter 레코드. 출발어 수를 늘리는 데 사용하지 않는다.
- **표현**: 띄어쓰기와 조사·어미를 포함한 고정된 말뭉치가 의미 단위인 경우
  독립 검색 단위 후보로 세되, 단순 활용형은 표현으로 만들지 않는다.
- **중복**: 같은 표면형을 품사나 의미만 달리해 나누는 경우 하나의 출발어로
  세고, sense를 나눈다. 완전히 다른 표제어를 숫자에 중복해 넣지 않는다.
- **선정 이유 코드**: 각 후보는 아래 범주와 코드를 하나 이상 가진다. 범주는
  개별 단어를 정당화하는 짧은 이유이며, 실제 canonical 수록 여부는 별도의
  검수 상태로 추적한다.

| 코드 | 선정 이유 |
| --- | --- |
| E | 정서·내면 상태를 직접 찾는 빈도가 높고 감정의 세기·방향을 비교하기 좋다. |
| Q | 성질·태도·온도·질감처럼 문장의 결을 바꾸는 말이다. |
| S | 소리·빛·냄새·맛·몸의 감각을 장면으로 확장하기 좋다. |
| C | 시간·자연·공간·장면을 통해 추상어를 이미지로 옮길 수 있다. |
| A | 움직임·관계·변화의 동작을 찾아 문장의 동세를 바꿀 수 있다. |
| O | 사물·몸·쓰기 재료처럼 구체적인 이미지의 닻이 된다. |
| X | 다의어·품사 경계·표현 단위처럼 모델을 흔드는 사례다. |

## 대표 40개와 경계 플래그

M1-1의 대표 묶음은 연속된 ID 40개가 아니라, 300개 후보에서 실제 경계 사례를
고르게 포함하도록 고른 아래의 정확히 40개다. 이 단계에서는 canonical lexical
record를 만들지 않는다. 각 ID는 후보 선정 이유를 추적하기 위한 식별자이며,
후속 태스크에서 검수 결과가 보류·제외될 수 있다.

## 목표 집계와 검수 상태

| 항목 | M1-1 계획 | 최종 기록 위치 |
| --- | ---: | --- |
| 검색 출발어 후보 | 300 | 이 문서의 `w001–w300` |
| M1-1 대표 출발어 후보 | 40 | 이 문서의 명시적 대표 ID 목록; canonical 수록은 후속 검수 |
| 참조 완결용 대상어 | 별도 집계 | canonical의 `pilot_role: reference`와 decision log |
| 미검수 후보 | canonical에 넣지 않음 | 저장소 밖 임시 영역 |

후속 배치의 실제 수록 수는 이 계획과 다를 수 있다. 빠진 항목을 억지로
채우지 않고, `included`, `held`, `duplicate`, `reference-only` 상태와 사유를
최종 count 표에 남긴다. 목표 수보다 대표성과 검수 가능성이 우선이다.
