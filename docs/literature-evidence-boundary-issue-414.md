# 문학 근거 검색기 오탐 감소 (#414)

원문·발췌·근거 팩은 Git에 포함하지 않는다. 이 문서는 텍스트 없는 집계와 사전 고정 기준만 담는다. 선행: [#391 보고](literature-evidence-pilot-report-issue-391.md), [#392 검증 계획](literature-evidence-validation-plan.md). 이 이슈는 #392 통합을 구현하지 않고, 문학 빈도를 어휘 admission 권한으로 쓰지 않으며, 검색기가 POS·뜻·처분을 판단하지 않는 계약도 유지한다.

## 개선안 (가장 작은 것)

기존 DB와 읽기 전용 질의 계층만 쓴다. 새 인덱스·재빌드·스키마 변경은 없다.

- `matchMode = eojeol`(**opt-in**, `--match-mode eojeol` 또는 `matchMode: 'eojeol'`): 검색형이 **어절 시작**에서 일치한 unit만 센다. 어절 시작이란 행 시작이거나 바로 앞 문자가 문자·숫자(`\p{L}\p{N}`)가 아닌 위치다. 오른쪽은 열어 둔다(조사·어미 결합 허용). 총 일치 수, 작품 수, 형별 상한 표본, 선택이 모두 같은 필터를 쓴다.
- `matchMode = substring`(**기본값**): #414 이전 동작. 판정(C)이 사전 기준을 충족하고 소유자가 전환을 결정하기 전에는 기본값을 바꾸지 않는다. 회귀 테스트가 기본값이 `substring`이고 모드 없이 호출하면 이전과 같은 결과를 내는지 고정한다.
- 이 필터로 해결되는 유형: 합성어·접두 결합·인명의 **뒷부분**(`꾀꼬리`⊃`꼬리`, `윤선도`⊃`선도`, `가지고`⊃`지고`). 해결되지 않는 유형(비목표 또는 후속 근거): 어절 **시작**에서 일치하는 한자 동형어·다른 표제어(`경고`(警告/硬告)), 인명이 어절 첫머리인 경우, 하드랩으로 쪼개진 형.

## 측정 기준 (측정 전에 고정)

코호트는 #391 재현 코호트(`literature-replay-cohort.mjs`): 과거 deferred 전부(123 + 실패 1)와 명확 included 40건. 같은 전수 DB·같은 검색형·같은 기본 설정(`max_contexts=8`, `max_per_work=1`, `hit_fetch_cap=2000`)으로 `substring`과 `eojeol`을 비교한다. 개선 효과는 #392 검증 12건(`literature-validation.mjs`의 `selectCohort`가 결정)을 **제외한 deferred 집단**에서 보고하고, 12건은 회귀 확인용으로만 따로 보고한다. 12건에 맞춰 규칙을 조정하지 않는다.

### A. 구조 측정 (결정적, 판정자 불필요)

히트 unit을 일치 위치로 분류한다: `boundary`(어절 시작), `after_hangul`, `after_han`, `after_other`. `boundary` unit은 일치 직후 한글 연속 길이(0 / 1–2 / 3+ 음절)로 나눈다. 이는 의미 오탐률이 **아니라** 필터가 제거하는 질의 결과의 구조 분포다.

### B. 정당한 일치의 재현율 손실 허용 한도 (사전 고정)

정당한 일치(활용형·조사 결합)는 어절 시작에서 일치하므로 필터 대상이 아니어야 한다. 의미 정답 없이 쓸 수 있는 대리 지표와 한도:

1. 전체 코호트에서 문맥 0개 사례가 `substring` 대비 **2건 넘게 늘면 안 된다**.
2. 전체 코호트에서 문맥 3개 미만 사례가 **6건 넘게 늘면 안 된다**.
3. 명확 included 40건에서 `eojeol/substring` 정확 unit 비율의 중앙값이 **0.5 미만이면 안 된다**.

한도를 넘으면 필터를 기본값으로 쓰지 않는다.

### C. 오도 근거 비율 (판정자 필요, 위임 판정은 위임으로 기록)

의미 정답은 소유자 또는 소유자가 위임한 판정자의 기록만 쓴다. 위임 판정을 소유자 직접 판정으로 기록하지 않는다. 에이전트(Claude)는 판정하지 않는다. 판정 단위는 히트 unit이고 라벨은 `same_word`(후보 표제어·활용형·조사 결합 그대로의 쓰임) / `other_word`(인명, 합성어, 다른 표제어의 일부, 한자 동형어 중 하나로 세부 유형 기록) / `unclear`(분모에서 제외하고 건수 보고)다.

- 사전 등록 수정(2026-10-08, 라벨 요청 **전**, 어떤 라벨도 읽기 전): 층화 표본(후보당 제거 ≤3 + 유지 ≤3)은 층 크기를 반영하지 않으므로 비가중 비율로 기준을 판정하면 작은 제거 층의 과대표집이 결과를 좌우한다. 이를 막기 위해 후보별·층별 고유 unit 수(`population`)와 선택 수(`selected`)를 `mapping.local.json`에 기록하고, 각 판정 히트에 `population/selected` 가중치를 준 **층 가중 추정량**으로 모든 비율을 계산한다. 필수 필드(`candidate_id`, 정수 `population >= selected >= 1`)가 없거나, 같은 후보·층의 행들이 서로 다른 `population/selected`를 갖거나, `selected`가 그 후보·층의 mapping 행 수와 다르면 집계가 거부된다(fail-closed). 모집단은 검색기가 읽는 형별 2,000 unit 산포 표본의 고유 unit이며 전체 말뭉치가 아니다. `unclear`는 비율에서 빼고 건수와 가중 unit 수를 보고한다. 표본 불확실성은 95% 구간(2000회, 후보 id에서 시드를 정해 결정적)으로 상대 감소와 제거 `same_word` 비율에 대해 보고한다. 1단계는 후보를 복원 추출한다. 2단계는 모집단보다 적게 뽑은 (후보×층) 셀마다 관측 라벨 수에 Jeffreys 사전(0.5)을 둔 Dirichlet 사후분포에서 셀의 라벨 비율을 뽑아 셀 모집단에 곱한다. 관측값만 복원 추출하면 뽑은 히트가 모두 같은 라벨일 때 구간이 한 점으로 줄지만, 사후분포는 뽑지 않은 unit의 라벨을 불확실하게 남긴다(예: 500개 중 5개가 모두 `same_word`여도 나머지에는 `other_word`가 있을 수 있다). 전수 셀(`selected = population`)은 관측값 그대로 쓴다. 유효 재표본이 90% 미만이면 구간은 `null`(`evaluable: false`)이다. 셀당 최대 히트 수는 3에서 5로 올렸다(라벨 요청 전 수정). `criteria_met`은 **구간이 두 기준을 모두 넘을 때만** `true`(상대 감소 구간의 하한 ≥ 1/3, 제거 `same_word` 구간의 상한 ≤ 10%)이고, 점추정만의 충족은 `point_estimate_meets_criteria`로 따로 보고하며 판정으로 쓰지 않는다. 기준 값(상대 1/3 감소, 제거 `same_word` ≤ 10%)은 바꾸지 않았다.
- 표본: 12건을 제외한 deferred에서 `sha256("sample-414:" + 후보 id)` 순 앞 30건, 후보당 `substring` 히트 중 제거되는 unit 최대 5개 + 유지되는 unit 최대 5개를 같은 규칙(`sha256("hit-414:" + 위치 digest)` 순)으로 뽑아 순서를 섞어 맹검으로 제공한다.
- 개선 판정(사전 고정): `other_word` 비율이 `substring` 표본 전체에서 `eojeol` 유지 표본 쪽에서 **상대 1/3 이상 감소**하고, `same_word` 중 제거되는 비율이 **10% 이하**이면 "기준 충족"이다. 판정 전에는 충족 여부를 주장하지 않는다.
- 판정이 없으면 이 문서는 A·B만 보고하고 C는 "미판정"으로 둔다. `criteria_met`은 이 표본의 탐색적 추정이며 그 자체가 기본값 전환 권한이 아니다. 전환은 소유자 결정이 필요하다.

## 결과

측정: `pnpm run reference:literature:boundary:measure` (전수 DB 동일, 텍스트 없는 집계). 실패 1건(`C000003-0331`, 1자 표제어)은 검색형이 없어 양쪽에서 제외된다.

### A·B. 구조 분포와 재현율 손실 (163건)

| 집단 | 사례 | 문맥 0개 (전→후) | 문맥 3개 미만 (전→후) | 평균 문맥 (전→후) | 정확 unit 합 (전→후) | 표본 중 제거 unit 비율 | unit 유지율 중앙값 |
|---|---|---|---|---|---|---|---|
| 전체 | 163 | 3 → 3 | 4 → 4 | 7.78 → 7.75 | 196,046 → 145,203 | 21.4% | 0.956 |
| 과거 deferred | 123 | 3 → 3 | 4 → 4 | 7.71 → 7.67 | 159,720 → 126,337 | 19.3% | 0.957 |
| 명확 included | 40 | 0 → 0 | 0 → 0 | 8.00 → 8.00 | 36,326 → 18,866 | 29.6% | 0.939 |
| #392 12건 (회귀 확인용) | 12 | 0 → 0 | 0 → 0 | 8.00 → 8.00 | 21,823 → 12,135 | 35.4% | 0.969 |

- 제거 unit의 위치 분포(전체 표본 101,122개의 고유 unit; 여러 검색형에 걸린 unit은 한 번만 세고, 하나라도 어절 시작이면 유지): 어절 시작 79,483(78.6%) 유지, 한글 뒤 21,609(21.4%), 한자 뒤 3, 기타 문자·숫자 뒤 27. 유지 unit의 일치 직후 한글 연속(가장 짧은 값)은 0음절 51,873, 1–2음절 24,194, 3음절 이상 3,416.
- 사전 고정한 재현율 손실 한도 3개를 모두 충족했다(문맥 0개·3개 미만 사례 증가 0건, included 유지율 중앙값 0.939 ≥ 0.5). 12건의 문맥 수는 변하지 않았다.
- 한자 동형어는 일치 위치가 어절 시작이므로 이 필터로 줄지 않는다(표본에서 한자 뒤 일치는 3 unit에 불과). 즉 #391이 지적한 한자 동형어 잡음은 이 개선 범위 밖이다.
- 유지율이 0.5 미만인 사례는 9건(전체)이다. 이들은 짧은 표제어가 다른 어휘 중간에 자주 나오는 경우로, 어절 경계 필터가 가장 크게 작용하는 곳이다.
- 한계: 제거된 unit 중 일부(접두 결합 `되-`, 합성어의 후행 요소)는 같은 단어일 수 있다. 이 구분은 구조 측정으로 알 수 없다.

### C. 오도 근거 비율

**미판정.** 이 PR은 맹검 표본 생성(`pnpm run reference:literature:boundary:judge -- prepare`)과 라벨 검증·집계(`-- report`) 도구까지만 제공한다. 위임 판정자가 `labels.json`을 기록하기 전에는 오도 근거 비율의 감소, 허용 한도 충족, `same_word` 제거 비율을 주장하지 않는다. A·B만으로는 오탐이 줄었다고 결론 내리지 않는다.

### 결론과 한계

- 필터는 사전 고정한 가용성 한도를 모두 만족하면서 일치 unit의 약 26%(총합 기준)를 제거한다. 제거된 것은 모두 어절 중간 일치다.
- 오도 근거가 실제로 얼마나 줄었는지는 C 판정 후에야 확정된다. **그때까지 `eojeol`은 opt-in 실험이고 기본 검색은 바뀌지 않는다.** 이 PR은 #414를 닫지 않는다(수용 기준의 판정 부분이 남아 있다). 판정이 기준을 충족하고 소유자가 결정하면 기본값 전환은 별도로 한다. 충족하지 못하면 원인과 한계를 이 문서에 보고하고 기본값을 유지한다.
- 비목표 항목(관용구, 1자 표제어, 흔한 형 상한, 하드랩)은 손대지 않았다.
