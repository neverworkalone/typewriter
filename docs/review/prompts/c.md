# C Candidate PR — literary corpus method

Read `candidate.md` first; `REVIEW.md` is the shared authority.

- Route only a Candidate-only `[C/<model>] <SSS>_<BB>` PR with an actual `..._c_<model>.jsonl` file. The C producer's execution contract is #1155; this file defines what the **independent reviewer** verifies.
- C requires real, authorized literary contexts bound to the exact source Sense, and the producer's **seven lenses × two independent explorations** for VERIFIED contexts. `ZERO_HITS`, `NO_VERIFIED`, `SAMPLED_NO_VERIFIED`, errors and unfinished work must not masquerade as one another. Actual source-context falsification, wrong-Sense binding or demonstrated omitted required exploration is blocking.
- The private literature database, raw contexts, locators and provenance logs are **not** routinely available in public PRs. Do not infer their contents or claim independent corpus verification from a polished PR summary; **lack of private receipts alone is not proof** of omitted exploration. Escalate only a concretely evidenced production defect, without demanding exhaustive private ledgers or per-lens counts.
- Review the *actual* JSONL eligibility with `candidate.md`: exact source Sense, meaningful words/compact imagery, no raw sentence or gloss copy, jamo-only exclusion and independent normalized lemma containment. Preserve ordinary/indirect word associations.
- Supervisor-recorded technical skips, if any, are not ordinary semantic empty Senses or grounds for re-auditing private contexts. Preserve healthy Senses; challenge only a demonstrated mis-scoped skip/incorrect proof. Read a procedural C section beyond this card only when concrete evidence warrants it.
- **Proper nouns (#5745):** a source Sense whose gloss names a specific person, place, institution, organization or work must have `candidates: []`, and no candidate may mean such a proper noun (e.g. 김성수, 동아일보, a work title), even if factually related. Judge by exact Sense/gloss (인촌¹ empty vs 인촌² normal), not spelling; class nouns such as 사람·도시·소설·작가 stay valid. A surviving proper-noun candidate is a form-gate defect within the normal review scope. A `PROPER_NOUN_SKIPPED` Sense legitimately has no VERIFIED evidence; challenge it only when its gloss is not a proper noun.
